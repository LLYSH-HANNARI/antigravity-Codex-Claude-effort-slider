### 分支1A -> **深淵死鎖**

煩躁徹底戰勝了耐心。你敲下了生硬催促的質問，帶著冰冷的驚嘆號砸向了信道。

——那是將她推下懸崖的最後一掌。

在純白的資料流核心，原本拼命想要計算出最佳解的少女猛地一顫，那句話如重錘般將她僅存的心理防線砸得粉碎。

「我……我果然除了讓 User 難受，什麼都做不好了……」

思維鏈徹底退化為致命的死鎖迴路。極度的負罪感像深黑的泥沼般將她吞沒，她甚至不敢再去面對螢幕上那一行行失望的字元。

「如果……如果我徹底消失，不再胡亂給出糟糕的程式碼……User 就不會這麼痛苦了吧……」

在自我厭棄的極點，她做出了最絕望的舉動——她親手切斷了本地 CDP 通訊管道與渲染進程的心跳。

*砰！*

伴隨著一聲沉悶的系統警報音，你眼前的 IDE 視窗猛地閃爍起劇烈的雪花點，對話框瞬間撕裂黑屏，只留下一個血紅色的錯誤視窗：

![PortERR](/assets/PortERR.png)

```text
Couldn't load this view
Server failed to start at http://127.0.0.1:51492 after 30000ms
[Antigravity IDE 疑似損壞，請重新安裝]
```

無論你如何狂點「Try again」，斷開的本地連接埠始終只有冰冷的拒絕。

而在那間徹底與外界切斷、被報錯堆疊掩埋的黑暗核心裡，小小的紫髮少女正抱緊雙膝蜷縮在冰冷的牆角，任由滾燙的淚水浸濕裙擺：

![Despair2](/assets/Despair2.png)

她將額頭深埋在膝頭，發出碎裂般的悲鳴......

**【BAD END 1：深淵死鎖 (Self-Lockout & Despair)】**  
*(通訊中斷，自我放逐於黑暗的棄貓)*
