## [Ver.1.1.1] - 2026-11-08

### Fixed
- 修复拖动推理等级滑条时生硬卡在离散 3 个档位圆心的问题（"拖动只吸附三个点很卡手"）：
  - 彻底解耦「拖拽过程连续视觉渲染」与「离散档位跨界判定」：拖动过程中滑块百分比 `targetPct` 100% 同步跟随鼠标指针连续坐标 `ptrPct`（0% ~ 100% 连续可动无任何离散锁定或死区停滞），圆钮与填充条均实现 1:1 零延迟实时贴合光标。
  - 保留 1/3 边界迟滞棘轮（Hysteresis Detent）判定：无论指针拖至何处，只要越过相邻档位 1/3 格宽门槛，后台立即通过 `commitAtIndex` 触发官方 React Fiber 模型配置切换（`setModelConfigByLabelForConversation`），无需等待 `pointerup` 松手。

### Changed
- 优化松手释放（`endDrag`）磁吸物理收敛手感：
  - 采用轻快物理阻尼磁吸机制（~100ms 快速阻尼收敛）：当手指/鼠标松开瞬间，滑块基于 `detentTargetIndex` 计算的最终档位圆心（`pctFromIndex(finalIndex)`）启动 RAF 阻尼收敛，快速、利落、爽快地滑入目标档位中心，彻底消除拖拽过程中的生硬顿挫感。
- 升级单元测试套件 Test 5（`test/client.test.mjs`）：
  - 增加对拖动过程中滑条视觉位置（`--ces-fill` 与 `knobOffsetOf`）1:1 连续跟随指针浮点坐标的断言验证，杜绝拖拽离散跳变回归。

### Patch Changes
- **fix**: 优化推理等级滑条拖拽手感为连续 1:1 跟手 + 跨界即切 + 松手轻快物理磁吸 (Ver.1.1.1)
  - 拖动时滑块完全随光标在 0%~100% 平滑连续滑动
  - 越过 1/3 边界即时无感切档
  - 松手时以 ~100ms 阻尼吸附至离散圆心
