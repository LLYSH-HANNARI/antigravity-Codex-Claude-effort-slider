## [Ver.1.2.0] - 2026-11-08

### Added
- 新增滑动至最高档（High）时模型选择面板物理微震颤反馈：
  - 当手指/鼠标拖拽、点击或键盘方向键切入最高档时，外层模型选择面板（`[data-testid="model-selector-panel"]`）自动触发约 0.18s 快速阻尼微震颤（`@keyframes ces-panel-shake`，左右 ±2.5px 快速衰减并伴随回弹），营造极具质感的物理撞击阻尼感。
  - 防抖与锁存机制：在最高档区间内部拖动微移不重复触发抖动；初始打开菜单或切换模型默认进入 High 时保持静默，杜绝多余视觉干扰。
- 新增最高档 "High" 文字模糊光斑爆散动效（约 0.4s 淡淡消失）：
  - 切入最高档瞬间，"High" 档位文字背后中心爆发一个径向羽化模糊光晕（`filter: blur(8px)` + 径向渐变扩散），配合文字本身的霓虹光影（`@keyframes ces-text-bloom`），在约 0.4 秒内平滑柔和淡出至完全透明（opacity 1 → 0），文字本身保留专属高亮色。
  - 主题自适应色彩体系：Codex 风格（Gemini Argon / Flash）采用电紫光晕（`rgba(168, 85, 247, 0.9)`），Claude 风格（Claude Opus / Sonnet）采用柔和紫罗兰光晕（`rgba(196, 181, 253, 0.9)`）。
  - 当从最高档回退至较低档位时，自动即时清理光斑状态。
- 新增无障碍体验适配：在开启系统减弱动画模式（`prefers-reduced-motion`）时，自动静默禁用面板震颤与光斑爆散。
- 新增单元测试断言（`test/client.test.mjs`）：
  - 覆盖切入最高档时 `ces-panel-shaking` 与 `is-glowing` 动画类名触发验证。
  - 覆盖 Codex（`rgba(168, 85, 247, 0.9)`）与 Claude（`rgba(196, 181, 253, 0.9)`）各自主题光晕颜色属性验证。
  - 覆盖最高档内微移不重复触发、回退低档位自动移除光斑的防抖状态机验证。

### Minor Changes
- **feat**: 增加滑动至最高档面板物理微震颤与 High 文字模糊光斑爆散动效 (Ver.1.2.0)
