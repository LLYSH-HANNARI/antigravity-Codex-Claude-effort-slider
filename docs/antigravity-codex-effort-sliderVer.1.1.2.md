## [Ver.1.1.2] - 2026-11-08

### Fixed
- 修复 Claude 推理条拖到约 80% 时点阵特效提前从轨道右侧冒出的问题
  - 根因：点阵 Canvas 铺满整条轨道（`inset: 0; width: 100%`），一旦越过 High 的 1/3 判定线（≈66.7%），扫掠就从轨道最右端未填充区开始绘制
  - 修复：Canvas 的 CSS 宽度改为 `var(--ces-fill)`，像素宽度每帧同步为圆钮中心位置，点阵只在已填充区（圆钮左侧）绘制，扫掠从圆钮向左推进

### Changed
- Claude 点阵特效改为按位置连续过渡（与 Codex 能量曲线同源）
  - 强度 `claudeIntensityFor` = energy^1.5：Low 无特效 → Medium ≈0.35（少量点阵）→ High 1.0（全量）
  - 速度 `claudeSpeedFor`：Medium 0.5×，比 High 慢一倍；流动相位按帧累加，拖动中变速不会跳帧
  - `paintDither` 的 `intensity` 参数同时控制底晕透明度、像素密度（按格固定哈希剔除，不闪烁）和像素亮度；intensity=1 时输出与旧版一致
- 入场扫掠只在「无特效 → 有特效」时播放一次，之后拖动只连续调整强度和速度
- Claude 填充渐变末端颜色随位置连续插值，不再在中点突变
- 移除「Claude 有能量时隐藏刻度点」规则（点阵已不覆盖未填充区，刻度点保持可见）

### Added
- Test 6 新增断言：中档点阵数量少于最高档且大于 0、强度 0 只清屏、强度/速度曲线在 0~100% 连续单调
